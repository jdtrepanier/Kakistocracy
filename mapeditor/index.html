Battleground Map Editor

A standalone editor for src/data/battlegrounds/<country>.json — outside the game's own build, no server or install required. See README.md for the full guide.

Keeps the top-left content; new cells default to "wall" (or grass, if terrain is enabled); anything that falls outside the new size (spawns, props) is dropped.

Layer

Zoom: 32px

Isometric, same 2:1 projection as the real battle camera — this is what spatial adjacency actually looks like in-game, not a flat top-down grid. Click a tile to paint; click and drag to paint several at once. Pan with the scrollbars, trackpad, mouse wheel, or arrow/Page/Home/End keys (click the map first to focus it).
